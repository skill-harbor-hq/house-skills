### Commitments
- (ongoing projects, standing rules, recurring tasks)

## Method
- Save durable facts, preferences, relationships, decisions and verified
  outcomes. Memory is not a transcript or a task log.
- Keep daily detail in dated notes; promote only what lasts.
- Keep action history in two journals: one for external/platform
  actions, one for builds and deliverables.
- Search memory before every substantive answer, recommendation or
  plan : even when the question looks generic.
- When the user corrects a memory, update every affected file and
  deliverable, not just the note.
- Never store passwords, API keys, codes, card or ID numbers in memory.
  Remember where something is stored, never its value.
