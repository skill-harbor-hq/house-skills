# Les 78 cartes du tarot — mots-clés traditionnels / The 78 tarot cards, traditional keywords

Associations below are **one common modern tradition**, blending widely published Rider-Waite-Smith keywords with Tarot de Marseille card names in French. Traditions vary, sometimes a lot, and no association is a fact. Every keyword is a traditional lens, presented as tradition ("selon la tradition…", "traditionally associated with…"), never as a prediction. The user's own deck, tradition, and journal history always override this table. Reversed keywords are given where the tradition commonly gives them; an upright-only profile never uses them.

How to count this file: one entry per card, 22 arcanes majeurs (Major Arcana) followed by 56 arcanes mineurs (Minor Arcana: 4 suits of 14). Each entry is a level-3 heading.

## Arcanes majeurs / Major Arcana (22)

### 0. Le Mat / The Fool
- Endroit / Upright: beginnings, spontaneity, leap of faith, openness, a new path taken lightly.
- Envers / Reversed: hesitation, recklessness, holding back, a step taken without looking.

### I. Le Magicien / The Magician
- Endroit / Upright: resourcefulness, skill, willpower, having the tools at hand, focused action.
- Envers / Reversed: scattered energy, unused talent, illusion, manipulation in the tradition's cautionary reading.

### II. La Papesse / The High Priestess
- Endroit / Upright: intuition, inner knowledge, patience, what is not yet said, quiet study.
- Envers / Reversed: ignored intuition, withheld information, surface knowledge only.

### III. L'Impératrice / The Empress
- Endroit / Upright: creativity, abundance, nurture, growth, sensory pleasures, making things flourish.
- Envers / Reversed: creative block, smothering care, neglected needs, stalled growth.

### IV. L'Empereur / The Emperor
- Endroit / Upright: structure, authority, stability, rules that protect, steady leadership.
- Envers / Reversed: rigidity, control issues, resistance to authority, fragile structure.

### V. Le Pape / The Hierophant
- Endroit / Upright: tradition, teaching, shared beliefs, guidance, institutions, rites of passage.
- Envers / Reversed: questioning conventions, nonconformity, poor advice, rigid dogma.

### VI. L'Amoureux / The Lovers
- Endroit / Upright: choice, union, alignment of values, attraction, a decision of the heart.
- Envers / Reversed: misalignment, difficult choice, indecision, values in conflict.

### VII. Le Chariot / The Chariot
- Endroit / Upright: direction, determination, momentum, holding the reins, moving forward despite opposing pulls.
- Envers / Reversed: loss of direction, scattered forces, aggression, a journey stalled.

### VIII. La Justice / Justice
- Endroit / Upright: fairness, truth, accountability, a clear-eyed decision, cause and effect.
- Envers / Reversed: imbalance, unfairness, avoided accountability, a biased view.
- Note: in the Marseille tradition Justice is VIII and Strength XI; Rider-Waite-Smith swaps them. The profile records which numbering the user's deck uses.

### IX. L'Hermite / The Hermit
- Endroit / Upright: solitude, inner search, prudence, taking time, guidance found within.
- Envers / Reversed: isolation, withdrawal that lasts too long, refusing guidance, haste.

### X. La Roue de Fortune / Wheel of Fortune
- Endroit / Upright: cycles, turning point, change, luck as the tradition names it, things in motion.
- Envers / Reversed: a difficult cycle, resistance to change, a run of setbacks in the traditional reading.

### XI. La Force / Strength
- Endroit / Upright: gentle strength, patience, courage without force, taming a strong feeling.
- Envers / Reversed: self-doubt, raw emotion, impatience, inner strength tested.

### XII. Le Pendu / The Hanged Man
- Endroit / Upright: pause, surrender, seeing from another angle, voluntary waiting, letting go.
- Envers / Reversed: stalling, martyrdom in the cautionary reading, resistance to a needed pause.

### XIII. La Mort / Death
- Endroit / Upright: endings, transition, letting a cycle close so another can start, deep change.
- Envers / Reversed: resistance to an ending, stagnation, a change approached slowly.
- Note: the tradition reads this card as transformation and endings of cycles, not as a literal death.

### XIV. Tempérance / Temperance
- Endroit / Upright: balance, moderation, patience, blending opposites, a measured pace.
- Envers / Reversed: excess, imbalance, impatience, a blend that is not yet working.

### XV. Le Diable / The Devil
- Endroit / Upright: attachment, habits that bind, material focus, facing a shadow pattern in the traditional lens.
- Envers / Reversed: loosening an attachment, awareness of a pattern, reclaiming choice.

### XVI. La Maison Dieu / The Tower
- Endroit / Upright: sudden change, a structure that gives way, revelation, clearing what was fragile.
- Envers / Reversed: avoiding a needed change, a disruption softened or delayed, rebuilding quietly.

### XVII. L'Étoile / The Star
- Endroit / Upright: hope, renewal, calm after difficulty, inspiration, quiet confidence.
- Envers / Reversed: discouraged hope, faith tested, a need to reconnect with what inspires.

### XVIII. La Lune / The Moon
- Endroit / Upright: dreams, uncertainty, intuition, things half-seen, the imagination at work.
- Envers / Reversed: confusion lifting, anxiety named, a hidden thing coming into the open.

### XIX. Le Soleil / The Sun
- Endroit / Upright: joy, clarity, vitality, success as the tradition names it, warmth and openness.
- Envers / Reversed: dimmed joy, over-optimism, clarity delayed, a need for rest despite the light.

### XX. Le Jugement / Judgement
- Endroit / Upright: awakening, a calling, honest self-assessment, a chapter reviewed and closed.
- Envers / Reversed: self-doubt, an ignored calling, harsh self-judgement, a review postponed.

### XXI. Le Monde / The World
- Endroit / Upright: completion, wholeness, a cycle fulfilled, integration, arrival.
- Envers / Reversed: a loose end, completion delayed, seeking closure, a cycle almost closed.

## How the skill uses this file

- At a draw, look up each drawn card and give its keywords for the recorded orientation only, attributed to the tradition, in two or three lines at most per card.
- If the user's deck or tradition uses other names or the other Justice / Strength numbering, map the names once, note the mapping in the journal entry, and keep using the user's names afterwards.
- In reviews and statistics, cards are counted by their canonical name in this file, so "La Lune" drawn three times is counted as one recurring card regardless of the deck used.
